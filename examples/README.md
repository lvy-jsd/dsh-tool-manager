# Examples

Two complete, runnable extensions. Both are kept working by the test suite, and
both are the same shape as a package generated by
[`create-dsh-tool-ultra-plugin`](../packages/create-dsh-tool-ultra-plugin).

| Example | Extension point | Shows |
|---|---|---|
| [`example-classifier`](example-classifier) | `registerClassifier` + `defineCategory` | placing a family of tools into a group and that group into a new category |
| [`example-filter`](example-filter) | `registerVisibilityFilter` | narrowing one agent's visible tools, and why a filter can only remove names |

Install either one into a profile the same way as any plugin:

```sh
dsh plugin --profile web add @lvy-jsd/dsh-tool-ultra-core ./examples/example-classifier
```

## Reading order

1. The core README's **Extending** section — the service surface and the events.
2. `example-classifier` — the smallest useful extension (about 30 lines).
3. `example-filter` — how to narrow without widening, and the entry-tool rule.

## Generating your own

```sh
npm create @lvy-jsd/dsh-tool-ultra-plugin@latest my-ext -- --type classifier
```

The four types are `classifier`, `filter`, `hook` and `declaration`; see the
scaffolder's README.
