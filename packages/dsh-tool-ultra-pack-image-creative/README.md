# @lvy-jsd/dsh-tool-ultra-pack-image-creative

Image creation, editing, and pixel operations for [Tool Ultra](https://github.com/lvy-jsd/dsh-tool-ultra).

High-performance image manipulation via [sharp](https://sharp.pixelplumbing.com/) (libvips) and AI generation endpoint adapters.

## Tools

| Tool | Group / category | What it does |
| --- | --- | --- |
| `image_metadata` | image / media | Inspect image dimensions, format, channels, color space, and alpha without dumping pixels into context. |
| `image_edit` | image / media | Resize, crop, rotate, flip, flop, grayscale, convert format (PNG/JPEG/WebP/AVIF), and adjust quality. |
| `image_generate` | image / media | Generate images from text prompts using local ComfyUI/SD or OpenAI-compatible image endpoints. |
