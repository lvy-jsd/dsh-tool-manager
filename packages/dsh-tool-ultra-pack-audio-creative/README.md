# @lvy-jsd/dsh-tool-ultra-pack-audio-creative

Audio creation, speech synthesis, and editing for [Tool Ultra](https://github.com/lvy-jsd/dsh-tool-ultra).

Neural text-to-speech (Edge-TTS) and ffmpeg-driven audio cutting and mixing.

## Tools

| Tool | Group / category | What it does |
| --- | --- | --- |
| `audio_synthesize` | audio / media | Generate natural speech from text using neural TTS models (multiple voices and languages). |
| `audio_cut` | audio / media | Cut and trim audio files with start, duration, or end timestamps. |
| `audio_mix` | audio / media | Mix voiceover and background music tracks with custom volume controls. |
