# @lvy-jsd/dsh-tool-ultra-pack-office

Office document reading and manipulation for [Tool Ultra](https://github.com/lvy-jsd/dsh-tool-ultra).

Pure JavaScript/TypeScript document parsing and generation: Word (.docx), Excel (.xlsx), and PDF metadata inspection.

## Tools

| Tool | Group / category | What it does |
| --- | --- | --- |
| `office_doc_read` | office / system | Extract text content and structure from Word documents (.docx) as Markdown/plain text. |
| `office_sheet_read` | office / system | Read rows and sheet data from an Excel spreadsheet (.xlsx). |
| `office_sheet_write` | office / system | Create a new Excel spreadsheet (.xlsx) with column headers and row data. |
| `office_pdf_info` | office / system | Read metadata, title, author, and page count from a PDF document. |
